# Archived Source Packages

These ZIP files are retained as supporting project artifacts. The extracted, actively used analysis outputs are organized in `reports/`, the Power BI report is in `powerbi/`, and dashboard previews are in `visuals/`.

- `Project_Source_Archive.zip` — original consolidated project/source package.
- `Dashboard_Assets_Archive.zip` — supporting dashboard asset package.

The ZIPs are retained for reference and are not required for browsing the repository's documented reports or dashboard previews. Check the contents and data redistribution terms before extracting or redistributing them.
